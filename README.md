# Dependency Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов Ubuntu (apt).

**Вариант:** 2  
**Дисциплина:** Конфигурационное управление  
**Студент:** Бакшун А.И.  
**Группа:** ИКБО-51-25

## 1\. Общее описание

Программа анализирует зависимости пакетов Ubuntu (apt) и визуализирует их в виде графа. Работает без использования готовых менеджеров пакетов (apt, dpkg) и сторонних библиотек для парсинга зависимостей.

Поддерживает:

* Чтение конфигурации из YAML-файла.
* Парсинг файла Packages (реального репозитория или локального тестового файла).
* Построение графа зависимостей (DFS с рекурсией).
* Поиск обратных зависимостей.
* Визуализацию в формате PlantUML и ASCII-дерева.

## 2\. Описание функций и настроек

Программа настраивается через файл config.yaml.

|Параметр|Тип|Описание|
|-|-|-|
|package\_name|string|Имя анализируемого пакета (например, nginx).|
|repository\_url|string|URL репозитория или путь к тестовому файлу.|
|test\_mode|bool|Режим тестирования (true — читать локальный файл).|
|package\_version|string|Версия пакета (например, 1.18.0).|
|ascii\_tree|bool|Выводить ли граф в виде ASCII-дерева.|
|filter\_substring|string|Подстрока для фильтрации пакетов.|

## 3\. Команды для сборки и запуска

Установка зависимостей:
pip install pyyaml requests

Запуск:
python src/main.py
или через скрипты:
./run.sh (для Linux/macOS)
run.bat (для Windows)

## 4\. Примеры использования

Пример конфигурации:
package\_name: nginx
repository\_url: test\_repo.txt
test\_mode: true
package\_version: "1.18.0"
ascii\_tree: true
filter\_substring: "zzz"

Пример вывода ASCII-дерева:
nginx
├── libc6
│   └── libcrypt1
├── libpcre3
└── zlib1g

"All tests passed"
