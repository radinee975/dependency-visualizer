# Dependency Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов Ubuntu (apt).

**Вариант:** 2
**Дисциплина:** Конфигурационное управление
**Группа:** ИКБО-51-25

## Описание

Программа позволяет анализировать и визуализировать зависимости пакетов Ubuntu без использования готовых менеджеров пакетов.

## Этап 1 — Минимальный прототип с конфигурацией

- Конфигурация через YAML-файл
- Вывод всех параметров
- Обработка ошибок

### Запуск

```
python src/main.py
```

или

```
./run.bat
```
