# Dependency Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов Ubuntu (apt).

**Вариант:** 2  
**Дисциплина:** Конфигурационное управление  
**Студент:** Бакшун А.И. 
**Группа:** ИКБО-51-25

## 1. Общее описание

Программа анализирует зависимости пакетов Ubuntu (apt) и визуализирует их в виде графа. Работает без использования готовых менеджеров пакетов (apt, dpkg) и сторонних библиотек для парсинга зависимостей.

Поддерживает:
- Чтение конфигурации из YAML-файла.
- Парсинг файла Packages (реального репозитория или локального тестового файла).
- Построение графа зависимостей (DFS с рекурсией).
- Поиск обратных зависимостей.
- Визуализацию в формате PlantUML и ASCII-дерева.

## 2. Описание функций и настроек

Программа настраивается через файл config.yaml.

| Параметр | Тип | Описание |
|----------|-----|----------|
| package_name | string | Имя анализируемого пакета (например, nginx). |
| repository_url | string | URL репозитория или путь к тестовому файлу. |
| test_mode | bool | Режим тестирования (true — читать локальный файл). |
| package_version | string | Версия пакета (например, 1.18.0). |
| ascii_tree | bool | Выводить ли граф в виде ASCII-дерева. |
| filter_substring | string | Подстрока для фильтрации пакетов. |

## 3. Команды для сборки и запуска

Установка зависимостей:
pip install pyyaml requests

Запуск:
python src/main.py
run.bat 

## 4. Примеры использования

Пример конфигурации:
```yaml
package_name: nginx
repository_url: test_repo.txt
test_mode: true
package_version: "1.18.0"
ascii_tree: true
filter_substring: "zzz"
```

Пример вывода ASCII-дерева:
```text
nginx
    ├── libc6
    │   └── libcrypt1
    ├── libpcre3
    └── zlib1g
```
